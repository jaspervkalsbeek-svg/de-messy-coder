## Testgebieden

### 1. Functionaliteit
- Werken alle links?
- Werkt de navigatie?
- Werkt het contactformulier?
- Werkt de database-connectie?
- Werkt dark mode?

### 2. Codekwaliteit
- Is de code netjes gestructureerd?
- Zijn er spelfouten in de code?
- Zijn er dubbele code (DRY)?
- Is de code leesbaar?
- Zijn er goede commentaren?

### 3. Beveiliging
- Staan er wachtwoorden in de code?
- Is er SQL-injectie mogelijk?
- Zijn er XSS-problemen?
- Zijn er andere beveiligingsrisico's?

### 4. Usability
- Is de website duidelijk?
- Werkt het op mobiel?
- Is de tekst goed leesbaar?
- Zijn er mime-fouten?

### 5. Performance
- Laadt de website snel?
- Zijn er grote afbeeldingen?
- Zijn er onnodige scripts?
